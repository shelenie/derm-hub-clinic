# Derm Hub — сайт клініки

Статичний сайт: HTML + CSS + JS, без збірки. Хостинг — Vercel (гілка `main` деплоїться автоматично).
Продакшн: https://derm-hub-clinic.vercel.app

## Структура
- `index.html` — українська версія (основна, тут редагуємо тексти).
- `en.html` — англійська, **генерується** з `index.html`: `node tools/build-en.js`. Руками не редагувати.
  Переклади — пари `[укр, англ]` у `tools/build-en.js`; ціни англійською — `js/prices-en.js`.
- `v1.html`, `v2.html` — робочі варіанти (закриті від індексації).
- `css/redesign.css` — базові стилі; `css/global.css` — дизайн-система й новіші правки (перекриває redesign.css).
- `js/prices.js` — прайс; `js/redesign.js` — уся поведінка сторінки; `js/vendor/` — бібліотека карти MapLibre.
- `img/` — фото, відео, фавікони, OG-картинки (`og-uk.jpg`, `og-en.jpg`).

## Як вносити зміни
1. Правка в `index.html` / CSS / JS.
2. Підняти версію `?v=N` у посиланнях на CSS/JS (index, v1, v2) — інакше браузери покажуть старе.
3. `node tools/build-en.js` — оновити англійську версію (скрипт показує тексти без перекладу).
4. Локально: `npx --yes serve -l 5173 .` → http://localhost:5173
5. Коміт і пуш у `main` → Vercel оновить сайт за ~1 хв.

Замінюєте картинку під тим самим іменем — додайте `?v=N` у посилання (картинки кешуються на 7 днів).
Змінили OG-картинку — підніміть `og-*.jpg?v=N` у `index.html` і `tools/build-en.js`.

## Сторонні сервіси
- Шрифти: Google Fonts. Карта: тайли OpenFreeMap (безкоштовно, без ключа; підпис © OpenStreetMap обов'язковий).
- Нові зовнішні скрипти/сервіси (аналітика, піксель, форма) треба додати в CSP у `vercel.json`, інакше браузер їх заблокує.
- Секрети (токени, ключі API) — тільки в змінних середовища Vercel, ніколи в коді.

## Що ще не готово
- Фото хіро — стокове (заглушка), замінити на відео/фото клініки.
- Відео «Про клініку» зі стоку з водяним знаком Stocksy — потрібна ліцензія або власне відео.
- Онлайн-запис — демо-форма: потрібна інтеграція з програмою запису клініки, підтвердження і нагадування в Telegram/SMS.
- Фото Оксани немає; фото Уляни низької якості.
- Частоти процедур у «Піраміді догляду», переклади і політику конфіденційності має підтвердити клініка.
- Власний домен (тоді замінити адресу в `index.html`, `tools/build-en.js`, `robots.txt`, `sitemap.xml`).
